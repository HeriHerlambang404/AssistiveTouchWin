# AssistiveTouchWin

Assistive Touch floating widget for Windows with integrated local AI (llama-server) and desktop automation capabilities. Built with PyQt5.

## Features

- Floating assistive touch bubble for Windows desktop.
- Local AI integration via llama-server (OpenAI-compatible local endpoint).
- Quick actions, shortcuts, and automated control using PyAutoGUI.
- Lightweight and customizable UI.

## Requirements

- Python 3.10+
- PyQt5
- PyAutoGUI
- requests

## Installation

```bash
# Clone repository
git clone https://github.com/HeriHerlambang404/AssistiveTouchWin.git
cd AssistiveTouchWin

# Setup virtual environment
python -m venv .venv
# On Windows:
.venv\Scripts\activate

# Install dependencies
pip install PyQt5 pyautogui requests
```

## Usage

```bash
python assistive_ai.py
```
